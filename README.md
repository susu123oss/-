# 植物大战僵尸 iOS 辅助插件 (PVZSun)

适用于 iOS 越狱环境（Rootful / Rootless / RootHide）的植物大战僵尸底层功能增强插件。

## 功能特性
1. **阳光不减反增**：种植植物消耗阳光时，实际增加对应数值阳光。
2. **免费种植**：种植植物零阳光消耗。
3. **种植无冷却**：植物卡片瞬间就绪，无需等待冷却转圈。
4. **全屏自动吸附**：掉落阳光与金币生成即自动吸附收集。
5. **植物绝对无敌**：多点拦截僵尸啃咬、重砸与碾压伤害，铲子仍可正常移除。

## 构建与打包
```bash
# 编译生成 arm64 + arm64e 双架构 dylib
make

# 编译并打包 deb 安装包
make package FINALPACKAGE=1
```
